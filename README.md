
# v2ray-tester 🧪

یک ابزار قدرتمند برای تست، رتبه‌بندی و مدیریت کانفیگ‌های V2Ray / Xray.

> کانفیگ‌هات رو تست کن، سرعتشون رو اندازه بگیر، مرتب‌شون کن و بهترین‌ها رو انتخاب کن.



---

## این ابزار چکار می‌کنه؟ (توضیح ساده)

فرض کن کلی لینک ساب‌اسکریپشن یا کانفیگ V2Ray داری (مثل vmess، vless، trojan و...).  
این ابزار به‌جای تو، تک‌تک کانفیگ‌ها را از طریق هسته اصلی Xray اجرا می‌کند، بررسی می‌کند که آیا واقعاً به اینترنت وصل هستند یا نه، پینگ و سرعت واقعی دانلود آن‌ها را اندازه می‌گیرد، کشور سرور را پیدا کرده و در نهایت بهترین‌ها را برایت گلچین و مرتب می‌کند.




---

## 🚀 نصب و راه‌اندازی سریع (Quick Start)

اگر می‌خواهید بدون معطلی کار را شروع کنید، این ۴ مرحله را انجام دهید:

۱. **دریافت پروژه:**
```bash
git clone https://github.com/someviberdude/realyrank
cd realyrank
```

۲. **نصب کتابخانه‌ها:**
```bash
pip install -r requirements.txt
```

۳. **قرار دادن هسته Xray:**
فایل Xray مخصوص سیستم‌عامل خود را از [اینجا](https://github.com/xtls/xray-core/releases) دانلود کنید و در پوشه پروژه قرار دهید (نام پوشه را طبق جدول پایین تنظیم کنید).

۴. **اجرا:**
لینک‌های خود را در `subs.txt` قرار دهید و دستور زیر را بزنید:
```bash
python main.py --auto
```



## نیازمندی‌ها

### ۱. Python 3.8 یا بالاتر
پکیج‌های مورد نیاز (در فایل `requirements.txt` موجود است):
```bash
# پکیج‌های اصلی
pip install aiohttp aiohttp-socks ipwhois-python

# پکیج‌های اختیاری (برای ظاهر زیباتر و سرعت بیشتر)
pip install rich tqdm uvloop
```

### ۲. فایل Xray (هسته اصلی)
فایل اجرایی Xray باید در مسیرهای زیر (کنار فایل‌های پروژه) باشد:

| سیستم‌عامل | مسیر و نام فایل |
|------------|----------|
| **ویندوز** | `Xray-windows-64/xray.exe` |
| **لینوکس** | `xray-linux-64/xray` |
| **مک** | `xray-macos-64/xray` |

## چطور استفاده کنم؟ (روش‌های مختلف)

### ۱. روش تعاملی (دستی)
اگر می‌خواهی مرحله‌به‌مرحله پیش بروی و لینک‌ها را همان‌جا وارد کنی:
```bash
python main.py
```

### ۲. روش خودکار (فقط با ساب‌اسکریپشن)
لینک‌های ساب را در `subs.txt` بنویس (هر خط یک لینک) و اجرا کن:
```bash
python main.py --auto
```

### ۳. تست حجیم (مناسب برای فایل‌های سنگین)
برای تست سریع تعداد زیادی کانفیگ از یک فایل متنی:
```bash
python v2ray-bulk-tester.py -i configs.txt -o results.txt -c 20
```
- `-i`: فایل ورودی
- `-o`: فایل خروجی
- `-c`: تعداد تست همزمان (Concurrency)

### ۴. رتبه‌بندی و تغییر نام (Ranking)
برای مرتب‌سازی کانفیگ‌های سالم بر اساس سرعت و تغییر نام آن‌ها به فرمت استاندارد:
```bash
python main.py --rank -i working.txt -o ranked.txt
```
فرمت خروجی: `[RANK - COUNTRY - SPEED - PING] Name`

## مراحل تست (Pipeline)

ابزار، هر کانفیگ را از ۷ فیلتر عبور می‌دهد:

1.  **Dedup:** حذف لینک‌های تکراری.
2.  **Ping:** بررسی زنده بودن سرور (۳ ثانیه مهلت).
3.  **Latency:** تست تاخیر اتصال واقعی (۵ ثانیه مهلت).
4.  **Cleanup:** حذف ساب‌های غیرفعال.
5.  **Speed Test:** تست سرعت واقعی با دانلود ۵ مگابایت دیتا.
6.  **Geo Location:** پیدا کردن کشور سرور از روی IP.
7.  **Ranking:** امتیازدهی و مرتب‌سازی نهایی.

## فایل‌های پروژه

| فایل / پوشه | نقش |
|------|------|
| `subs.txt` | محل قرار دادن لینک‌های ساب‌اسکریپشن برای شروع. |
| `working.txt` | خروجی نهایی کانفیگ‌های تست شده و سالم. |
| `bad_subs.txt` | ذخیره لینک‌های ساب‌اسکریپشن که خراب بودند. |
| `config.html` | ابزار جانبی برای مدیریت و ادغام ساب‌ها در مرورگر. |
| `v2ray_tester/` | پکیج اصلی شامل کدهای فنی، پارسرها و توابع تست. |

## ساختار پوشه‌بندی

```text

├── requirements.txt       ← لیست کتابخانه‌ها

```

## نکات امنیتی 🔒
